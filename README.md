# Denada's D&D Hairsalon

**Live site: [https://desolatemartial553.github.io/dd-hairsalon/](https://desolatemartial553.github.io/dd-hairsalon/)**

A mockup website for **Denada's D&D Hairsalon**, a hair salon in Northfield, Birmingham, built on spec to show the owner what a modern site could look like. It is a demo and is not run by or affiliated with the business.

- **Design:** Ethereal editorial beauty
- **Built with:** plain HTML, CSS and JavaScript. No framework, no build step, self-hosted fonts and images.
- **Hosting:** GitHub Pages, served from the `main` branch.

To run it locally, open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
